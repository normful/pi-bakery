# @normful/pi-socrates

When Pi needs your input, it asks with an interactive picker instead of making you type a free-form reply.

## Installation

```bash
pi install npm:@normful/pi-socrates
```

## What you see

One question shows a quick picker. Multiple questions show tabs with a Submit tab to review everything before sending.

Pi's suggestion is marked `(Recommended)`. Pick any option, or pick `Other` to type your own answer. Press `Tab` on any option to attach a short note.

## Keyboard shortcuts

- `Up` / `Down`: move between options
- `Left` / `Right`: switch question tabs
- `Enter`: select, toggle, or submit on the Submit tab
- `Tab`: add or edit a note on the current option
- `Esc`: cancel
